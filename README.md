# حُضور — نسخة العرض

نسخة عرض تفاعلية من منصة **حُضور (HUDUR.AI)** — منصة الهوية المهنية الذكية.

▶️ **التجربة المباشرة:** https://ahmadalrabea-cell.github.io/hudur-demo/

- تعمل كاملة داخل المتصفح بلا خادم ولا تسجيل.
- تبدأ فارغة؛ ما تُدخله يبقى في متصفحك فقط ولا يُرسل لأي جهة.
- توليد الذكاء الاصطناعي في هذه النسخة محاكاة محلية — النسخة الكاملة تعمل عبر خادم.

هذا المستودع يحوي ملف العرض المبني فقط؛ الكود المصدري في مستودع خاص.
